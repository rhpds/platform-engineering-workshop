== Module structure

The workshop is split into multiple independent modules that can be completed in any order. You won't be writing code or hand-crafting YAML -- you will mostly be deploying pre-built configurations and observing the results.

**Want to see results faster?** Modules 3 (GitOps Fundamentals), 4 (Secrets Management), and 5 (Namespace as a Product) provide foundational background knowledge but can be skipped if you are most interested in seeing the platform in action. Jump directly to the Developer Hub modules to experience the unified developer portal, software catalog with AI/agentic integration (MCP, Lightspeed), and self-service templates with automated supply chain security gates (SBOM generation, vulnerability scanning, compliance enforcement).

IMPORTANT: Read this page in its entirety to understand the environment and how to use the web terminal.

== How you will work

You will primarily use a GitOps-driven configuration approach. This means you will use OpenShift GitOps to deploy and manage platform components. Its user interface is available in the **Argo CD** tab on the right. Don't worry if GitOps is new to you -- it'll be explained as you follow the content. It essentially boils down to a set of YAML files in a Git repository being continuously reconciled against your OpenShift cluster. We're taking a production-like approach in this workshop! 😎

=== Using the tabs on the right

The instructions stay on the left while you work with the workshop tools in the tabs on the right. Click a tab to switch tools as each exercise directs:

* **OCP Console** -- The OpenShift Web Console for exploring cluster resources, Operators, and pipelines
* **Argo CD** -- The OpenShift GitOps user interface for viewing Applications, changing their configuration, and checking deployment status
* **Developer Hub** -- The developer portal you will configure and explore
* **Vault** -- The secrets management interface
* **Keycloak** -- The identity and SSO administration console
* **GitLab** -- The source code, configuration, and catalog repositories
* **Terminal** -- The workshop terminal for running commands

=== Executable terminal commands

Throughout the workshop, you will see command snippets with a terminal icon in the top-right corner. Select the terminal tab on the right, then click terminal icon in the snippet to automatically execute the command in the Wetty terminal tab.

Try it now. Select the **Terminal** tab, then click the terminal icon in the top-right corner of the code snippet below:

[source,bash,role="execute"]
----
oc version --client
----

This should display your OpenShift CLI version. You can also copy commands and paste them manually, but the play button makes it faster!

TIP: You can use the `clear` command at any time to clean up the terminal output and start fresh.
